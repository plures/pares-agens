# Pares Agens

**Local-first AI agent framework.** Runs entirely on your hardware — no cloud required.

Pares Agens combines a reactive event loop, offline-first memory (pluresLM), and P2P mesh sync
across all your devices. Write custom procedures in Rust, connect any OpenAI-compatible model,
and chat over the local terminal or Telegram.

## Where to Start

New here? Follow the [Getting Started](getting-started.md) guide. You'll install the agent,
configure a model, and send your first message in under 5 minutes.
