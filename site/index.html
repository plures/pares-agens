Features

Intelligence that stays with you

Everything you need to run a sovereign AI that learns, remembers, and acts — without sending a byte to the cloud.

⚡

Reactive Event Loop

Procedure-based architecture with a reactive event loop. Every message, timer, or state change triggers the right handler automatically.

📴

Offline-First

Works completely without internet. Local inference with Qwen3 runs on your hardware — your conversations never leave your network.

🔗

P2P Mesh Sync

Sync memory and state across all your devices using Hyperswarm. No central server, no single point of failure.

🧠

Unified Memory

pluresLM remembers conversations, code patterns, and desktop interactions in one searchable store that persists across sessions.

🤖

Custom Procedures

Author your own agent behaviors as typed procedures. Compose them into powerful workflows with full control over triggers and outputs.

🛠️

MCP Tool API

Expose any capability as an MCP tool. Connect external services, automate GUIs, or query databases from one unified interface.

📱

Cross-Platform Nodes

Lightweight capability nodes run on Windows, macOS, mobile, and browser. One agent brain controls all your platforms.

🔒

Privacy by Design

All communication is Noise-protocol encrypted. Audit logs are stored locally in PluresDB. Zero telemetry, full transparency.

💬

Multi-Channel

Chat via local terminal or Telegram. More channels coming soon — the agent is the same, only the interface changes.

FAQ

Frequently asked questions

Is Pares Agens really free?

Yes. The Free tier has no time limit and no feature cutoff for single-machine use. Run unlimited conversations with any model indefinitely. Pro adds multi-device P2P sync and cloud backup for $9/mo.

Can I use my own API keys?

Absolutely. Bring your own keys for OpenAI, Anthropic, Gemini, or any OpenAI-compatible endpoint. Pares Agens never proxies your requests — API calls go directly from your machine to the provider.

Does it work without internet?

Yes. With a local model (Qwen3 via Docker Model Runner, or any GGUF-compatible model), Pares Agens runs completely offline. P2P sync also works over your local network without internet access.

How is memory different from ChatGPT's?

PluresLM memory is stored locally in an encrypted PluresDB instance on your machine. It persists across sessions, syncs to your other devices (Pro), and you can inspect or delete it at any time. Nothing is sent to a cloud memory service.

What hardware do I need?

Any modern Windows, macOS, or Linux machine. For local inference, 8 GB RAM is the minimum for smaller models (Qwen3-4B). For cloud-only model use, any basic laptop is sufficient.

Is my data private?

All data lives on your machine. No telemetry is ever collected. P2P communication is end-to-end encrypted with the Noise protocol. When you use cloud model APIs, only your message content is sent to that provider — nothing else leaves your machine.
