Features

Intelligence that stays with you

Everything you need to run a sovereign AI that learns, remembers, and acts — without sending a byte to the cloud.

⚡

Reactive Event Loop

Procedure-based architecture with a reactive event loop. Every message, timer, or state change triggers the right handler automatically.

📴

Offline-First

Works completely without internet. Local inference with Qwen3 runs on your hardware — your conversations never leave your network.

🔗

P2P Mesh Sync

Sync memory and state across all your devices using Hyperswarm. No central server, no single point of failure.

🧠

Unified Memory

pluresLM remembers conversations, code patterns, and desktop interactions in one searchable store that persists across sessions.

🤖

Custom Procedures

Author your own agent behaviors as typed procedures. Compose them into powerful workflows with full control over triggers and outputs.

🛠️

MCP Tool API

Expose any capability as an MCP tool. Connect external services, automate GUIs, or query databases from one unified interface.

📱

Cross-Platform Nodes

Lightweight capability nodes run on Windows, macOS, mobile, and browser. One agent brain controls all your platforms.

🔒

Privacy by Design

All communication is Noise-protocol encrypted. Audit logs are stored locally in PluresDB. Zero telemetry, full transparency.

💬

Multi-Channel

Chat via local terminal or Telegram. More channels coming soon — the agent is the same, only the interface changes.
