Migration from OpenClaw

Step-by-step guide to migrating an existing OpenClaw installation to Pares Agens.

Overview of changes

ConceptOpenClawPares Agens
Configurationopenclaw.json~/.config/pares-agens/config.toml
Plugin systemTypeScript pluginsRust procedures
Memory storeSQLite + custom schemaPluresDB (local vector store)
Model configPer-plugin model keyCentral [model] section
Telegram channelPlugin: @openclaw/telegramBuilt-in [[channels]] entry
CLIopenclawpares

Before you start

  1. Back up your OpenClaw data: 
    cp -r ~/.openclaw ~/.openclaw-backup-$(date +%Y%m%d)
  2. Note your current model and API key settings — you will re-enter them in the new config.
  3. Export your OpenClaw memory (if you want to migrate conversation history): 
    openclaw memory export --format json > openclaw-memory.json

Step 1 — Install Pares Agens

curl -sSL install-pares.plures.io | sh

Verify the install:

pares --version
# pares-agens 0.1.0

Step 2 — Initialise

pares agens init --name="my-assistant"

This creates ~/.config/pares-agens/config.toml.

Step 3 — Migrate model configuration

Open your old openclaw.json and locate the model settings. Translate them into the new format:

OpenClaw (openclaw.json)

{
  "model": {
    "provider": "openai",
    "apiKey": "sk-...",
    "model": "gpt-4o"
  }
}

Pares Agens (config.toml)

[model]
provider = "openai"
base_url = "https://api.openai.com/v1"
model    = "gpt-4o"
# Set OPENAI_API_KEY env var instead of storing the key here

See the Model Configuration guide for the full reference.

Step 4 — Migrate channel configuration

OpenClaw

{
  "plugins": [
    { "name": "@openclaw/telegram", "token": "123456789:ABCdef..." }
  ]
}

Pares Agens

[[channels]]
type  = "telegram"
token = "123456789:ABCdef..."
allowed_ids = [987654321]

See Channel Setup for all options.

Step 5 — Import OpenClaw memory (optional)

If you exported your memory in Step 0, import it into pluresLM:

pares agens memory import --format openclaw openclaw-memory.json

This converts each OpenClaw memory entry into a pluresLM conversation memory with the original timestamp preserved.

Note: Only text-based memories are migrated. Attachments and binary data are skipped.

Step 6 — Migrate custom plugins

OpenClaw plugins written in TypeScript need to be rewritten as Rust procedures. The concepts map directly:

OpenClaw pluginPares Agens equivalent
onMessage handlerProcedure with handles(Event::Message)
onTimer handlerProcedure with handles(Event::Timer)
memory.store()MemoryClient::capture()
memory.search()MemoryClient::recall()
model.complete()ModelClient::complete()

See Procedure Authoring for full examples.

Step 7 — Test the migration

pares agens start
pares agens chat

Send a test message. Verify the agent responds and memory is working:

pares agens memory list --limit 5
✅ Migration complete! Your agent is now running on Pares Agens with the same model and channel configuration as OpenClaw.

Getting help

If you run into issues during migration, open an issue on GitHub with the migration label.
