Channel Setup

Channels are the interfaces through which you talk to your agent. Configure the local terminal for development and Telegram for on-the-go access.

Available channels

ChannelUse caseRequires
local Terminal REPL, development Nothing extra
telegram Chat from phone / tablet Telegram bot token

Local channel (default)

The local channel is enabled by default. Start it with:

pares agens chat

To explicitly configure it in config.toml:

[channels.local]
enabled = true
prompt  = "You"     # label shown in the terminal

Telegram channel

1. Create a bot

  1. Open Telegram and search for @BotFather.
  2. Send /newbot and follow the prompts.
  3. Copy the HTTP API token BotFather gives you.

2. Configure

Add to ~/.config/pares-agens/config.toml:

[channels.telegram]
enabled = true
token   = "${TELEGRAM_BOT_TOKEN}"   # reads from environment

# Optional: restrict to specific Telegram user IDs for security
# allowed_user_ids = [123456789]

3. Set the environment variable

export TELEGRAM_BOT_TOKEN="1234567890:ABCdef..."

Or add it to your shell profile / systemd unit / NixOS config.

4. Start the agent

pares agens start

Open your Telegram app, find your bot, and send it a message. Replies come back instantly.

⚠️ Security Without allowed_user_ids, anyone who finds your bot can interact with your agent. Always restrict to your own Telegram user ID in production:

allowed_user_ids = [YOUR_TELEGRAM_USER_ID]

Find your ID by messaging @userinfobot on Telegram.

Running multiple channels simultaneously

Enable both channels in the same config and start the agent once — messages from all channels share the same memory and conversation state:

[channels.local]
enabled = true

[channels.telegram]
enabled = true
token   = "${TELEGRAM_BOT_TOKEN}"
pares agens start   # runs all enabled channels concurrently

Channel status

pares agens status
# ✅ Channels: local, telegram (connected)
