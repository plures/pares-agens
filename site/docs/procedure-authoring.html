Procedure Authoring

Extend Pares Agens with custom behaviors by writing typed Rust procedures. Procedures are first-class event handlers that plug into the reactive event loop.

Concepts

Events

Everything in Pares Agens is driven by events. An event carries a typed payload and is dispatched by the executor to all registered handlers:

  • Event::Message — an inbound chat message from any channel
  • Event::ModelResponse — a completed model response
  • Event::Timer — a periodic timer tick
  • Event::StateChange — an arbitrary key/value state update

Procedures

A procedure is an async handler that receives an event context and returns a Vec<Event> of follow-up events to inject back into the loop. Built-in procedures include OnMessage, AutoRecall, and AutoCapture.

Your first procedure

Create a new crate or add to an existing one:

# in Cargo.toml
[dependencies]
pares-agens-core = { git = "https://github.com/plures/pares-agens" }

Implement the Procedure trait:

use pares_agens_core::{event::Event, procedure::Procedure};
use async_trait::async_trait;
use uuid::Uuid;

pub struct GreetHandler;

#[async_trait]
impl Procedure for GreetHandler {
    fn name(&self) -> &str {
        "greet"
    }

    fn handles(&self) -> &str {
        "message"   // matches the string returned by Event::kind() for Message variants
    }

    async fn execute(&self, event: &Event) -> Vec<Event> {
        let Event::Message { channel, content, .. } = event else {
            return vec![];
        };

        if content.to_lowercase().contains("hello") {
            return vec![Event::Message {
                id: Uuid::new_v4().to_string(),
                channel: channel.clone(),
                sender: "agent".into(),
                content: "Hey there! 👋".into(),
            }];
        }

        vec![]
    }
}
📌 Key rule Handlers must be pure with respect to side effects on the event loop. All follow-up work is expressed as returned events, never by directly calling other handlers.

Register your procedure

Register the procedure on a ProcedureRegistry and pass it to the executor:

use pares_agens_core::{executor::Executor, procedure::ProcedureRegistry};

let mut registry = ProcedureRegistry::new();
registry.register(Box::new(GreetHandler));
registry.register(Box::new(OnMessage::new(
    memory_client,
    model_client,
    tool_dispatcher,
    "You are a helpful assistant.",
)));

let executor = Executor::new(registry);
executor.run(&source, 0 /* unlimited */).await;

Working with memory

Inject a MemoryClient to recall past conversations from pluresLM:

use pares_agens_core::{
    event::Event,
    memory::{Memory, MemoryClient},
    procedure::Procedure,
};
use std::sync::Arc;

pub struct SummaryHandler {
    memory: Arc<dyn MemoryClient>,
}

#[async_trait]
impl Procedure for SummaryHandler {
    fn name(&self) -> &str { "summarise" }
    fn handles(&self) -> &str { "message" }

    async fn execute(&self, event: &Event) -> Vec<Event> {
        let Event::Message { id, channel, sender, content } = event else {
            return vec![];
        };

        // Recall relevant memories
        let memories: Vec<Memory> = self.memory.recall(content, 5).await;

        // Prepend recalled context to the message content
        let context: String = memories.iter()
            .map(|m| format!("[memory] {}", m.content))
            .collect::<Vec<_>>()
            .join("\n");

        let enriched = if context.is_empty() {
            content.clone()
        } else {
            format!("{context}\n\n{content}")
        };

        vec![Event::Message {
            id: format!("{id}-enriched"),
            channel: channel.clone(),
            sender: sender.clone(),
            content: enriched,
        }]
    }
}

Timer-based procedures

Use OnTimer to drive scheduled behaviour. Implement TimerAction for each named timer:

use pares_agens_core::{
    event::Event,
    handlers::on_timer::{OnTimer, TimerAction},
    procedure::ProcedureRegistry,
};
use async_trait::async_trait;
use std::sync::Arc;

struct DailySummaryAction;

#[async_trait]
impl TimerAction for DailySummaryAction {
    async fn execute(&self) -> Vec<Event> {
        println!("Daily summary running…");
        vec![] // return follow-up events if needed
    }
}

let on_timer = OnTimer::new();
on_timer.register("daily_summary", Arc::new(DailySummaryAction));

let mut registry = ProcedureRegistry::new();
registry.register(Box::new(on_timer));

State-change watchers

Use OnStateChange to react to PluresDB key updates. Implement WatcherAction for each watched key:

use pares_agens_core::{
    event::Event,
    handlers::on_state_change::{OnStateChange, WatcherAction},
    procedure::ProcedureRegistry,
};
use async_trait::async_trait;
use std::sync::Arc;
use uuid::Uuid;

struct BatteryWatcher;

#[async_trait]
impl WatcherAction for BatteryWatcher {
    async fn on_change(&self, event: &Event) -> Vec<Event> {
        let Event::StateChange { new_value, .. } = event else {
            return vec![];
        };
        let level = new_value.as_u64().unwrap_or(100) as u8;
        if level < 20 {
            return vec![Event::Message {
                id: Uuid::new_v4().to_string(),
                channel: "alerts".into(),
                sender: "agent".into(),
                content: "⚠️ Battery low!".into(),
            }];
        }
        vec![]
    }
}

let on_state_change = OnStateChange::new();
on_state_change.watch("battery_level", Arc::new(BatteryWatcher));

let mut registry = ProcedureRegistry::new();
registry.register(Box::new(on_state_change));

Testing your procedure

All dependencies are trait objects, so testing is straightforward with inline mock implementations:

#[cfg(test)]
mod tests {
    use super::*;
    use pares_agens_core::{
        event::Event,
        memory::{Memory, MemoryCapture, MemoryClient},
    };
    use async_trait::async_trait;

    struct MockMemory;

    #[async_trait]
    impl MemoryClient for MockMemory {
        async fn recall(&self, _query: &str, _limit: usize) -> Vec<Memory> {
            vec![]
        }
        async fn capture(&self, _entry: MemoryCapture) -> Result<(), String> {
            Ok(())
        }
    }

    #[tokio::test]
    async fn greets_on_hello() {
        let handler = GreetHandler;
        let event = Event::Message {
            id: "1".into(),
            channel: "test".into(),
            sender: "user".into(),
            content: "hello world".into(),
        };
        let events = handler.execute(&event).await;

        assert_eq!(events.len(), 1);
        assert!(matches!(events[0], Event::Message { .. }));
    }
}
✅ Tip Run cargo test --workspace to validate all procedures including your custom ones.
