Complete reference for MCP tool definitions, Event variants, core traits, and CLI commands.

MCP Tools

Pares Agens exposes its capabilities to the model as MCP (Model Context Protocol) tools. Tools are invoked by the model during a response and executed by the ToolDispatcher.

memory_search

FieldTypeDescription
Input: querystringFree-text search query
Input: limitinteger (optional, default 5)Max results to return
OutputArray<Memory>Ranked memory entries with score, text, and metadata
 
// Example model invocation
{
  "name": "memory_search",
  "arguments": { "query": "last week's meeting notes", "limit": 3 }
}

// Response
[
  { "id": "mem_abc", "text": "Meeting on 2026-02-20...", "score": 0.94 },
  ...
]

memory_store

FieldTypeDescription
Input: textstringContent to store
Input: tagsArray<string> (optional)Labels for later filtering
Output{ id: string }ID of the created memory entry

shell_exec

FieldTypeDescription
Input: commandstringShell command to run
Input: cwdstring (optional)Working directory
Output{ stdout, stderr, exit_code }Combined output
⚠️ Capability node required shell_exec requires a capability node running on the target machine. The agent core alone cannot execute shell commands.

http_get / http_post

FieldTypeDescription
Input: urlstringRequest URL
Input: headersobject (optional)HTTP headers map
Input: bodystring (optional, POST only)Request body
Output{ status, body }HTTP response

Event variants

VariantFieldsEmitted by
Event::Message{ id, channel, sender, content }Channel adapters (local, Telegram); OnMessage response
Event::ModelResponse{ request_id, model, content }OnMessage handler
Event::Timer{ id, name, recurring }Executor clock; OnTimer reschedule
Event::StateChange{ key, old_value, new_value }PluresDB state updates
Event::ToolResult{ tool_call_id, tool_name, content, is_error }ToolDispatcher

Core traits

Procedure

#[async_trait]
pub trait Procedure: Send + Sync {
    /// Unique name for this procedure (e.g. `"on_message"`).
    fn name(&self) -> &str;

    /// The event kind this procedure handles (matches [`Event::kind`]).
    fn handles(&self) -> &str;

    /// Execute the procedure in response to the given event.
    async fn execute(&self, event: &Event) -> Vec<Event>;
}

ModelClient

#[async_trait]
pub trait ModelClient: Send + Sync {
    async fn complete(
        &self,
        messages: &[ChatMessage],
        tools:    &[ToolDefinition],
    ) -> Result<ModelCompletion, String>;
}

MemoryClient

#[async_trait]
pub trait MemoryClient: Send + Sync {
    async fn recall(&self, query: &str, limit: usize) -> Vec<Memory>;
    async fn capture(&self, entry: MemoryCapture) -> Result<(), String>;
}

ToolDispatcher

#[async_trait]
pub trait ToolDispatcher: Send + Sync {
    async fn available_tools(&self) -> Vec<ToolDefinition>;
    async fn call_tool(&self, name: &str, arguments: serde_json::Value) -> String;
}
