Model Configuration

Connect Pares Agens to any AI model — local Ollama, self-hosted inference clusters, or OpenAI-compatible cloud APIs.

Configuration file

All model settings live in ~/.config/pares-agens/config.toml under the [model] section.

Option 1 — Ollama (recommended for local use)

Install Ollama, pull a model, and point the agent at it:

# Pull a model first
ollama pull llama3
ollama pull qwen2.5:72b   # for heavier reasoning tasks
[model]
provider = "ollama"
base_url = "http://localhost:11434"
model    = "llama3"

# Optional generation parameters
temperature    = 0.7
max_tokens     = 4096
context_window = 8192
💡 Recommended models llama3 for general chat, qwen2.5:72b for complex reasoning, codestral for code-heavy tasks.

Option 2 — OpenAI-compatible API

Any OpenAI-compatible endpoint (OpenAI, Azure OpenAI, Together.ai, Groq, etc.) works with the openai provider:

[model]
provider = "openai"
base_url = "https://api.openai.com/v1"   # or any compatible endpoint
model    = "gpt-4o"
api_key  = "${OPENAI_API_KEY}"           # reads from environment
⚠️ Privacy note Using a cloud API sends your messages to a third-party server. For full privacy, use a local provider such as Ollama.

Option 3 — Local Qwen3 cluster (self-sovereign)

For maximum capability and privacy, run Qwen3 235B-A22B distributed across multiple machines:

Hardware requirements

SetupHardwareModelSpeed
Budget 1× 64 GB RAM machine Qwen3 70B (Q4) ~15 tok/s
Optimal 3× Mac Mini M4 Pro (48 GB each) Qwen3 235B-A22B ~30 tok/s

Cluster setup

# Provision a 3-node Qwen3 cluster
pares agens setup-local-inference \
    --nodes=3 \
    --memory=48gb-each \
    --model="qwen3-235b-a22b"

# Verify inference is working
pares agens test-inference
[model]
provider    = "ollama"
base_url    = "http://node-1.local:11434"
model       = "qwen3-235b-a22b"
fallback    = "http://node-2.local:11434"  # automatic failover

Multiple model profiles

Define named profiles and switch between them per procedure:

[model.profiles.fast]
provider = "ollama"
model    = "llama3"

[model.profiles.heavy]
provider = "ollama"
model    = "qwen3-235b-a22b"

[model]
default = "fast"

Reference a profile in a procedure:

let model = ctx.model("heavy");  // uses the heavy profile
